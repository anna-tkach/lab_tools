Це фіча для створення структурованої прийнятої ієрархії папок для проектів та репозиторіїв в директорії Lab.
Можливі власники проектів - own (я) чи client-id.
Проект - це продукт. Власник може мати багавто продуктів.
Репозиторій - це конкретний спосіб реалізації продукта. Проект може мати багато репозиторіїв. 

Тобто прийнята натспуна структар 
    Власник -> проекти -> репозиторії.
